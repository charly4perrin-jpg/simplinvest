# Stratégie de Contenu LinkedIn — Personal Branding pour Commerciaux

## POSITIONNEMENT

**Pour qui** : Commerciaux, BDR, SDR, Account Managers, indépendants sales
**Problème résolu** : LinkedIn sous-exploité = leads manqués, invisibilité, profil muet
**Promesse** : Transformer leur profil en source de leads entrants qualifiés
**Différenciant** : Tu documentes la méthode en live sur toi-même d'abord

---

## 4 PILIERS DE CONTENU

### Pilier 1 — MÉTHODE (40% des posts)
> Ce que les gens peuvent appliquer immédiatement

Exemples de sujets :
- "5 choses à changer sur ton profil LinkedIn ce soir"
- "Comment rédiger un titre qui attire les bons prospects"
- "La structure d'un post LinkedIn qui génère des demandes de connexion"
- "Pourquoi ton À Propos fait fuir tes prospects (et comment le fixer)"

### Pilier 2 — RÉSULTATS / PREUVES (25% des posts)
> Ce qui donne envie de travailler avec toi

Exemples de sujets :
- Avant/Après profil client (avec permission)
- Screenshot d'un message entrant suite à un post
- "Ce que j'ai fait cette semaine pour mon client X"
- Métriques : impressions, demandes de connexion, RDVs générés

### Pilier 3 — MINDSET / VISION (20% des posts)
> Ce qui crée l'attachement et l'autorité

Exemples de sujets :
- "Le commercial de 2025 ne cold call plus. Il attire."
- "Pourquoi la majorité des commerciaux détestent LinkedIn (et ont tort)"
- "Ce que m'a appris mon chat sur le personal branding" ← signature récurrente
- Opinions tranchées sur le métier

### Pilier 4 — COULISSES / JOURNEY (15% des posts)
> Ce qui crée la connexion humaine et la confiance

Exemples de sujets :
- "Ce que j'ai appris en construisant ma méthode"
- "Voilà où j'en suis après 30 jours de posts quotidiens"
- "Mon premier client m'a dit X. Voilà ce que j'ai compris."
- Erreurs commises + leçons

## FORMATS QUI MARCHENT

### Format 1 : LISTE (le plus viralement partagé)
```
[Chiffre] [résultat contre-intuitif]

1. [Point court + explication 1 ligne]
2. [Point court + explication 1 ligne]
...

[Conclusion + question pour engager]
```

### Format 2 : STORYTELLING (le plus engageant)
```
[Situation de départ — 1 phrase accrocheuse]

[Problème / tension]

[Action prise]

[Résultat]

[Leçon applicable par le lecteur]

[Question ou CTA]
```

### Format 3 : AVANT / APRÈS (le plus convertissant)
```
Avant : [état du client / du profil]
Après : [résultat obtenu]

Voici exactement ce qu'on a fait :

→ Étape 1
→ Étape 2
→ Étape 3

Si tu veux le même résultat : [CTA]
```

### Format 4 : OPINION TRANCHÉE (le plus commenté)
```
[Affirmation polarisante]

[Argument 1]
[Argument 2]
[Argument 3]

[Nuance si nécessaire]

D'accord ou pas ? ⬇️
```

## CALENDRIER DE PUBLICATION

| Fréquence recommandée | 3-4 posts / semaine |
|-----------------------|---------------------|
| Jours optimaux | Mardi, Mercredi, Jeudi |
| Horaires | 7h30-9h00 OU 12h00-13h30 |
| Format fixe | 1 liste + 1 storytelling + 1 coulisses par semaine |

### Planning type semaine
- **Lundi** : Repos
- **Mardi** : Post méthode (liste actionnable)
- **Mercredi** : Post storytelling / résultat
- **Jeudi** : Post opinion / mindset
- **Vendredi** : Optionnel — coulisses / journey
- **Week-end** : Repos

## LA PATTE CRÉATIVE — LE CHAT

Utilise ton chat comme personnage récurrent pour illustrer des concepts.

Exemples :
- "Mon chat attend que je lui apporte sa gamelle. Tes prospects font pareil avec ton contenu."
- Photo du chat + légende sur le personal branding
- "Ce matin mon chat m'a regardé poster. Il m'a appris X chose."

→ Ça crée une signature visuelle mémorable
→ Les gens reviennent pour le chat autant que pour le contenu
→ Robin Tempe a sa bannière arc-en-ciel, toi t'as ton chat

## STRATÉGIE DE CROISSANCE

### Phase 1 — Warmup (Semaines 1-4)
- Objectif : 200-300 nouvelles connexions ciblées
- Action : 20 demandes de connexion/jour sur profils de commerciaux
- Message de connexion : court, sans pitch, juste "Je suis dans le même domaine"
- Commenter 10 posts/jour de comptes dans ta niche

### Phase 2 — Contenu (Semaines 5-12)
- Objectif : 500-1000 abonnés, premiers messages entrants
- Action : 3-4 posts/semaine, répondre à TOUS les commentaires
- Tester les formats, noter ce qui performe

### Phase 3 — Monétisation (Semaines 13+)
- Objectif : 1-3 clients
- Action : Post de présentation de ton offre, DM ciblés post-engagement
- Packager la méthode documentée comme offre
